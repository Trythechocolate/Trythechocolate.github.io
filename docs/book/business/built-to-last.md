# 《基业长青》

> 作者：吉姆·柯林斯

## 阅读体会：长青不是一种神话

在进入正题前，我想检讨一个点，本来计划多用碎片时间多看点书的，但是这个计划在期末月所在的时间里被搁置了许久，以至于再拾起这本书的时候几乎已经忘记了之前读过的内容，好像是翻开了一本新书。我希望在接下来的阅读计划当中能够保持一种吸收和思考的连贯性，让不同章节的内容能够融会贯通起来。

作者在序言中提到过《基业长青》（Built to Last）这个书名，说这本书并不是说如何创建一家能够“长青”的公司，而是说我们应该创建一家值得“长青”的公司——创建一家具有内在品格的公司。用更可感的语言来说，就是如果这家公司不幸消亡，那么世界会怅然若失。我想这的确算是一个“胆大包天的目标”，但这也是让无数商业王国的缔造者，或者想要亲手创造一个奇迹的创业者，闻之振奋的目标。

这本书最有价值的在于四个主要观念：做造钟师而非报时人，拥护兼容并蓄的融合法，保存核心并追求进步，追求连续一贯的协调一致。

我很喜欢造钟师和报时人这个比喻。两个角色似乎都能达到告知人们时间的作用，但区别在于，造钟师着眼于钟从内至外的机械设计，并不时地审视自己的杰作是否能够达到预期的目标，通过不断地修改迭代以期作品能得到长久的使用；而报时人只关注眼前报出的时间是否准确，至于如果自己离开岗位该由谁接替，是否会因为时间渐长产生倦怠甚至纰漏他毫不关心。公司或者组织也是这样，影响一个公司是否能够获得长远发展的最重要的因素不在于是否在初期就拥有一个伟大构想，或者是否有一个魅力型领袖筹划一切，而是深植于公司内部的基本程序和根本动能。这某种程度上甚至降低了创造一个高瞻远瞩公司的心理成本，因为我们不必等待那些看起来有点随机、有点捉摸不透的因素，而只需要从最基本的入手，搭建起一个科学合理的组织，我们就在一点点地塑造一个公司的内在品格。

当我们卸下心理负担之后，就应该大胆地着手创造。那么我们应该从哪些方面进行创设呢？哪些是一家值得长久经营的公司应该具有的品质呢？为了介绍这一点，有意思的是，作者引入了中国的太极生两仪来说明兼容并蓄的重要性：我们常常认为两种相反的品质天然相斥，但事实上不是的。比如价值观导向的理想主义和利润导向的务实主义、创新创造的自主性和严格控制的纪律性、计划指引下的进步和机会主义式的探索……斯科特·菲茨杰拉德所指出的“检验一流智力的标准，就是在头脑中存在两种相反的想法而保持行动的能力。”当这句话映入我的眼帘时，打破了我许多固有思维，让我意识到很多问题或许在提出的时候就是一个假命题。我们并不需要执着于偏向哪一方，也不必在两者之间寻求妥协，而是要在两方面都做得淋漓尽致。当然，这当然是非常困难的，这意味着我们要把原来用于专攻某一方面的精力翻倍用于两个方面，但至少我们少了另外一层负担——担心自己在某一方面的努力会反噬另一方面，从而畏手畏脚。

对于兼容并蓄的融合法一个绝佳的例子就在于——保存核心并追求进步。说得更详细具体一点，核心即公司的理念价值观，进步即对涉足领域、产品定位、管理方式等方面的革新。或许听起来司空见惯，但这本书的价值在于，作者为追求进步划分了一个尽可能大的腾挪空间——除了核心理念之外的一切。界定一项改革应不应该实行的标准，并不在于它是否延续了过去的做法，它是否与市场上广泛认同的理念相契合，而在于它是否能够淋漓尽致地贯彻本公司的核心价值。除此之外，作者提供了很多令人深受启发并且可以付诸实践的案例，比如，为了驱动创新，3M公司设置了“15%的规定”（研发人员可以把15%的时间花在自选的研究计划上），为了保障服务质量，万豪通过“幽灵顾客”的方式考核第一线服务人员的服务水平……这些未听过却顿觉高明的细节，再一次证明了公司就像一个时钟，它的运转是极为精妙的，需要它的设计师根据多样化的需要绞尽脑汁去构思每一个螺丝、每一个齿轮的衔接之处。

追求进步的方法论当中，作者提出了不少颇有新意的观点。最让我深受感触的在于“胆大包天的目标”，作者在章首引用了老罗斯福的一段话“尝试伟大的事情，赢取光荣的胜利，即使遭遇失败，也远胜过与既不享受多少东西，也不承受多少痛苦的可怜虫为伍，因为他们活在不知战胜和败退为何物的灰色朦胧地带。”读到这句话的时候，就像一颗小石子击中我的后颈。我时常不敢面对那些过于宏大、过于耀眼的事物，羞于将自己的野心呈现出来。直到我看到了这一章当中，一个又一个动人心魄的宏伟目标：西屋的“在我们服务的每一个市场中，我们要成为数一数二的公司，并且改革公司，拥有小企业一般的速度和活力”，雷诺公司的“成为香烟行业里的通用汽车”，福特的“我们要让汽车大众化”，索尼的“我们希望改变日本产品品质低劣的形象”……这些目标的狂野之处，需要在与企业平庸现状的鲜明对比当中被凸显出来，创始人到底是有怎样的魄力、信念、和想象力，才能够去描绘这样一张光芒四射的蓝图，去与理智与谨慎的心态博弈，去相信自己能够做到一切决心要做的事。所以我又又何必试图掩藏自己的野心，只有胆大包天的目标，才能刺激出令人难以置信的前进动力。

其次是“教派般的文化”，这是一个容易引起歧义的定义，因为“教派”可能引发一些负面的想象和含义，但作者从四个特点详细阐释了教派和高瞻远瞩公司的企业文化的相似之处：热烈拥护的理念、灌输信仰、严密契合、精英主义。在管理学的课堂当中，邢老师一再强调企业文化的重要性，指出这是根植于企业内部的重要一环。但是我并不能够直观地感受到，什么样的企业文化称得上是出色的，企业文化在企业运转当中到底扮演着什么样的角色？在作者的例子当中，我得以略窥一二。令我印象最深刻的是诺思通的“诺家帮”和迪士尼“演员”角色，从员工手册小卡片和百胜冠军颁奖，到标准化的妆容和有魔力的文字，每一个细节的雕刻都在向组织成员强力灌输着企业文化。需要辩证看待的是，企业文化并不是一个对任何人奏效的迷魂汤，而是一种极为严格的筛选机制，把信任它、认同它、愿意矢志不渝地践行它的人逐级推高，并把与之相背的行为或人完完全全地从组织中剔除。所以企业文化有好坏之分吗？没有。只有适合与否的问题。但是企业文化的营造和贯彻有优劣之别，一家高瞻远瞩公司能够做到，从一线人员到管理层保持着一致的行事风格和规范，心系着共同的价值理念和奋斗目标。就像宝洁CEO约翰·斯梅尔在公司聚会上说的“我和宝洁人会面时，不论他们是波士顿的销售人员、象牙谷技术中心的产品开发人员，还是罗马的管理委员会成员，我都觉得是和同一种人说话，是我认识、我信任的宝洁人。”或许在实际生活当中，我们暂时并不会需要去管理如此庞大的团队，但即便是在小团队当中，每个人都理解、认同团队的共同目标，也应当是达到团结协作至关重要的一步。

除了目标与文化这些基础性的工作外，作者还提出了一个让组织长期葆有生机活力的变革之道——“择强汰弱的进化”。作者在说明这一点的时候，创造性地将达尔文的进化论与企业的进化进行了对比。进化论的核心观点，用达尔文自己的话来总结就是“增生、变化，最强者生存，最弱者死亡”，而企业也需要如此。企业要想保持活力和创造力，就需要在即便是有怀疑的时候，抓住机会、解决问题、尝试、实验，反正绝对不能不采取任何行动。但生物学理论和管理学理论的区别在于，一方面，企业在实施这种进化式的进步时，也需要采取目标和计划的手段，双管齐下才能保障进步的可持续性；另一方面，企业的进化式进步不是像生物进化一样由基因和环境所决定的，而是有意识的，朝着企业核心理念所指示的方向不断进行自我革新，绝非完全随机的掷骰子行为。需要强调的一点是，这种进化应当容忍错误，甚至应该说，错误是不可避免的，我们要做的是及时地停止错误的尝试，并从中得到某种经验教训。简单来说我们能够需要做的就是，大量的实验，选择有用的，抛弃无用的，把有用的及时地充分地付诸实践，以此进行无论是理念、产品、管理等等方面的更新。

从事业回到人身上，作者提出要培养“自家长成的经理人”。在这一章节当中作者主要说明了人才培养的重要性，以及应当尽早地制定人才培养、筛选、迭代计划。“自家长成”的反面是“外来引进”，外来引进的人才能力上不一定弱于公司内部的管理人员，但是在对公司核心理念的理解和认同上，通常没有内部人员那么深刻。因此，更容易使得公司的发展方向偏离初衷。不可否认的是，大到公司，小到社团、项目组，人与人之间必然存在智识、能力等方面的差异，但如果组织寻求长期发展，就不能仅仅依靠某一领导者运转，这无异于以一缕之任，系千钧之重。只有在组织尚未陷入继承断层之时，就致力于培养多个具有潜能并且深刻理解组织理念的管理者，并给予未来领袖充分的锻炼机会和施展空间，才能危机立于前而岿然若泰山。

最后一点，我甚至觉得作者（也许是译者）的表达有些冗余，“追求连续一贯的协调一致”，本质上强调的是，公司的核心价值应当贯彻于公司实际运转的方方面面，也就是中国人所说的“言行一致”、“表里如一”。在作者举出的三个例子当中，让我最为动容的是惠普的做法。他们的核心理念是“设计、制造和开发最完美的电子设备，促进科学进步和人类福祉”，为了这一理念，他们将科学贡献作为是否值得开发某一产品的重要标准，而非完全依赖市场广度和认可度，即便在市场占有率成为商界学界所趋之若鹜的目标之时，惠普也没有抛弃自己的理念，一如既往的坚持以科技贡献这一衡量标准。按照作者总结的来说，做到协调一致，就需要做到描绘整体图景、注重细节、集中力量、走自己的路、消除不协调、创新不忘守恒。颇有启发性的一个观点在于，作者引用社会认知研究的结果“个人会收集工作环境里的所有信号——不管是大是小——作为自己行事的参考。”很多信息的传达并不是通过语言，也不是通过贴在墙上的标语，而是通过一张名片、报告会的顺序、年终奖励的奖品等等细节。所以我们不应只在年度报告之类的宏观图景当中刻入我们的理念，而应当让它被印在公司或组织的一切行为之中。

这本书超乎各种方法论的价值在于，它告诉我们，一个高瞻远瞩、基业长青的公司并不是由魅力型领袖、千载难得的机遇或者深厚的财富积累所造就的，而是由持久的、踏实的、有方向的艰苦奋斗所造就的。它打破了我们的迷思，向我们验证了行动的可行性，而真正的开始是我们自行去检验书中的种种观点，亲手去造一座能够一直报时的钟，就像丘吉尔的那句话“这不是终点，甚至不是终点的起点，这是起点的重点”。
