# 《人类简史》

> 作者：尤瓦尔·赫拉利

## 阅读体会：从俯视到仰望——于人类进化史中探寻人之定位

“人猿相揖别，几个石头磨过，小儿时节”就如同毛主席的这首词，智人从不起眼的动物到地球主宰者，经历了漫长的时日，而作者尤瓦尔·赫拉利大刀阔斧地将这十万年的故事，分割为三次关键性的革命：认知革命、农业革命和科学革命。认知革命让智人拥有了创造想象秩序和虚构故事的能力，彻底超越其他物种；农业革命让智人从采集狩猎生活走向定居生活，生活方式和社会组织发生了革命性的转变；科学革命让智人成为神一样的造物主，获得整个地球的统治地位。

在认知革命当中，作者提出了一个很新颖的观点——大规模的人类合作是以虚构的故事为基础的。他用了八卦理论和“河边有只狮子”的理论解释了人类语言的特殊性，能够呈现复杂的社会关系，也能灵活组合提供更加庞杂的信息。但是他强调了人类语言更为与众不同的一点，在于能够编织出种种虚构的故事，让智人能够灵活地与无数陌生人合作。我们经常强调合作的重要性，却很少去思考：什么是我们合作的基础，什么样的人能够达成合作。关于虚构故事的理论启示我们，合作的基础在于思想观念的统一，而变革的基础，也在于思想观念的转变。这是智人胜于其他分支的远古人类以及其他物种的关键变量，也是为什么当今社会意识形态成为各国争先恐后想要的高地，因为由虚构的故事聚合起的力量，能使人类驶入进化的快车道，亦是社会安稳的基石。

但人类的史册上并非只有一章章的丰功伟绩，有太多的残暴杀戮被一个个被标榜为进化的高光时刻所掩盖。在翻阅这本书的时候，我常常会感到一种愧疚，尤其是在“毁天灭地的人类洪水”这一章，作者细数了人类对生态系统所犯下的种种罪行。无论是澳大利亚的双门齿兽，还是南美洲的巨型地懒，作者写道“在大西洋、印度洋、北冰洋和地中海星罗棋布的数千座岛屿几乎无一幸免，都惨遭类似的生态浩劫”，就像德国为自己曾经的法西斯罪行道歉一般，虽然并非亲手犯下的罪孽，但又何尝不是一个物种繁衍至今背负的深深血债呢？人类从泛灵论转向多神教，再转向一神教甚至调和主义，本质上是把人类和其他物种区分开来，将其挪至人神关系这场大戏的中心，而远古那些泛神论的神灵，则降位成了临时演员，甚至只是沉默的装饰品。

看到养牛场、养鸡场里那些自远古被人类驯化后便再无自由可言的个体，又想到每日自己正津津有味地食用着动物制品，莫名而生出一种无力感和悲哀。我是人类成为食物链顶端的既得利益者，但因此我就应该相信人类控制其他动物不过是优胜劣汰自由选择的结果，然后心安理得地享受着祖先赠与我的“福利”吗？

而到了农业革命时期，我被农业生产的出现是“史上最大骗局”这个观点所吸引。在教科书上白纸黑字地写着，“农业是人类文明产生与发展的物质基础，是人类从原始野蛮走向文明社会的关键推动力。农业的出现使人类从食物采集者转变为食物生产者，推动了定居生活、村落形成与人口增长，为私有制、阶级分化和早期国家的产生提供了前提。”如此多的褒奖，在作者眼中竟然成了一场骗局？作者指控的论据主要在于农业革命带来的人口爆炸和阶级分化，以及伴随而至的经济安全和人身安全问题。看到这里，我实在无法矢口否认农业革命给个体带来的弊端了。在一种学界观点看来，衡量物种成功的进化与否，评断标准就在于世界上其DNA拷贝数的多寡。观之小麦、玉米这些植物，或许纯粹的进化观点还有些道理，但对于像牛、羊、智人这些有着复杂情感的动物来说，进化的成功并不代表个体的幸福。

一个非常典型的例子在于“奢侈生活的陷阱”，换句话说，就是人类种种想让生活变得轻松的努力，反而给人带来无穷的麻烦。其原因就在于，随着技术发展与生活水平的提高，原本的奢侈品往往最后会成为必需品，而且带来新的义务。当电子邮件代替了传统信件，我们的通讯工具变成了日夜不息的闹铃。所以当我们在使用一种新技术的时候，应当时刻记住我们发明它时的初衷，而不是被小麦“奴役”那般，心甘情愿地成为服侍它的仆从。

在物质基础以外在精神层面，作者认为我们生活所依赖的秩序是由想象所建构的。之所以能够实现这一点，主要有以下三点原因：想象构建的秩序深深与真实的世界结合，同时塑造了我们的欲望并且存在于人与人之间思想的连接。听起来似乎十分抽象，但是倘若我们不在时空的视角下对比，怎会对自身所处的秩序有一丝一毫的质疑。这并不是说，现有的社会秩序是天马行空捏造出来的，也并非要证明现有秩序的不合理性，而是在告诉我们，无论是浪漫主义、消费主义，还是资本主义、共产主义，在接受每一个现代社会通过种种手段灌输进我们脑海的观念之前，不妨多一步审视和思考，真正地理解这些秩序为什么是可行的，相比旧秩序好在哪里，又应该如何进化和改变。

这又不禁让我联想到了种族主义和等级制度的存在，就像作者所指出的那样“各种等级制度的道德意义不一，某些社会的歧视也比其他社会更为严重或极端，但至少就目前学者研究，还没有一个大型人类社会能真正免除歧视的情形”。等级制度可以被看作一种社会标签，链接着社会资源的分配。无论是种族歧视、宗教歧视还是性别歧视，其存在的根基已然被生物学等理论所驳倒，但人类社会并没有实现真正的平等。谢丽尔·桑德伯格在《向前一步》当中揭露了职场中种种隐性的性别歧视现象，比如职场女性被刻画成“拿着公文包的差劲母亲”形象等等。我明白这是一个根系甚至可以追溯至远古时代的社会议题，想要改变并非一朝一夕之功，但至少我们需要意识到现状是什么样的，应该是什么样的，而不是理所应当地接受社会强加在我们身上的规训，这是改变的第一步。

从农业革命走向科学革命，其中不可跳过的一环在于全球化的阶段。从金钱、帝国到宗教，作者从影响全球化进程的三个角度解释了这一过程的必然性。金钱建立起陌生人之间共通的信任，使得各种贸易合作和产业建设得以进行；帝国促进了民族交融与文化涵化，用武力征服改变原有的社会发展进程；宗教则使得共同的价值观念在异质文化之间传播。

毋庸置疑，全球化的过程还受到了工业革命等因素的影响，但就像作者指出的，历史具有两点特质——混沌性和盲目性，并无法用线性的逻辑推导所展示。更加详细地说，混沌性体现在“会受到预测的影响而改变”，由此便扼杀了历史“在做出准确预测”方面的功能，而更加强调其在拓宽视野，提升人类理解能力的作用。盲目性则体现在历史并不是朝着提升人类福祉的方向演进的，其中有一个很有意思的观点“模因论”，指出像生物演化是基于“基因”这种有机信息单位的复制，文化演进是基于“模因”这种文化单位的复制，故而所谓成功的文化，就是特别善于复制其模因，丝毫不论这对于其人类宿主的成本或者利益。这似乎与“历史唯物主义”所提出的“历史总体上是前进的上升的”相悖，但倘若我们从两个角度去审视人类社会的发展，便能看到其间微妙的平衡：人类社过工业革命、科技革命不断革新着自身生存的物质基础，但是文化、观念、舆论、情绪等并不一定同步进步，技术的变革反而可能导致愚昧与偏见更高效的传播。所以我们应当时时刻刻警钟长鸣，通过自我审视与反省，让自身的思想保持先进性和纯洁性。

进入科学革命时代，作者用简练的语言总结了现代科学的三大信条：愿意承认自己的无知、以观察和数学为中心、以及取得新能力。反观现代社会，这三大信条似乎已经深深地嵌入我们的基因当中，成为我们思维前进的必然路径。在人工智能、深海探测、基因工程等领域，人类不得不承认自己还有很长的路要走，但依赖孜孜不倦的科学研究，我们认为自己有能力不断地接近自然的真相。这种信心的极致体现就是打败死亡的“吉尔伽美什计划”，在苏美尔人古老神话中最英勇善战的国王也无法战胜的死神，竟然成为了人类想要攻克的下一个目标。人类就像一个长大的孩童，随着身体逐渐健壮，思想逐渐成熟，对自己的能力愈发自信，制定下一个个看起来狂妄无比的目标。但正是这样胆大包天的举动，推着人类以前所未有的速度朝前进化。

科学的进化与两大推手紧密相关——帝国主义和资本主义。帝国主义的扩张需求给予了科学考察慷慨的资金协助和人力资源，使得科考队员们跟随船队走遍世界的各个角落；资本主义则为经济发展提供了一套新的运转框架，使得社会财富源源不断地积累；就差工业革命一把火，烧去了能源匮乏和原料短缺的阻碍，使得世界越来越被塑造成适合智人需求的样子。不容忽视的是帝国扩张与资本原始积累血腥的一面，无论是西班牙殖民者给阿兹特克人带来的种族灭绝，还是三角贸易中最为残忍的奴隶贸易，我们都无法跨过历史这样沉重的一页。

随着经济基础的革新，社会层面也发生着翻天覆地的变化。工业革命将家庭和社群这两个所有人类社会最基本的结构单位粉碎成了原子，使得它们的许多功能被国家和市场所取代。法院的出现制止了家族的私刑，流行商业文化将各地悠久的传统取而代之，我们在获得更多人身自由的同时，也感受着人与人之间的疏离。于是，现代所兴起两大想象社群——“民族”和“消费大众”填补了情感上的空缺，成为社会新的粘合剂。从更宏观的层面来看，科技的进步带来了“核子和平”，也就是四个因素形成的良性循环：核子末日的威胁促进了和平主义；和平主义使得战争退散、贸易兴旺；贸易增长导致和平利润升高和战争成本升高。如果这个理论确实成立的化，意味着现代是一个前所未有的更加和平的年代，而我们将见证着全球村的形成。

在整本书的最后，作者提出了这样一个问题，人类通过漫长的演进与发展，变得更快乐了吗？如果没有，那么发展农业、城市、文字、货币、帝国、科学和工业的意义在于什么呢？这的确是一个令人惊讶的问题，在我所阅读的以往的历史论著当中，历史学家们竭尽全力保持自己的客观性，为什么会将“快乐”这样一个通常意义下被认为由主观情感所主导的因素纳入考虑范围呢？但我想，这应当被视作一种历史学的进步，或者说是现代个人主义和历史学的结晶，我们开始从宏观的视角切至更加微观的视角，关心一个看似渺小的个体的悲欢。快乐的影响因素实在是数不胜数，既包括客观条件，也包括主观上的期望。解释快乐存在的形式也说法不一，是快感、意义、还是放下追求主观情感的执念？作者并没有给出一个确切的答案，但我想，这也是我们每个人需要思考的问题。现在的我，大约是把世俗所认可的成功作为快乐的标准，换句话说，我所谓的快乐，就是让个人对意义的错和现行的集体错觉达成同步。我深受感触的是佛教的观点，人类的主观感受没有任何的实质或意义，主观感受就只是一种电光火石的波动，每个瞬间都在改变。而苦真正的根源就在于“追求”主观感受这件事，不管追求的是什么，都会让人陷入持续的紧张、困惑和不满之中。所以我们不应执着于主观感受，而应当“发心清净”，追求“看清真相、内心平静、自利利他”，不让追求变成枷锁。

让我印象深刻的一个点还在于，作者很多时候并没有给我们一个具体的答案，有时仅仅抛出了一个问题，有时提供了许多不同的理论假说，他毫无羞愧地承认“这场讨论才刚刚起步，要得出确切的结论还为时过早。最重要的，是要了解各种不同的研究方法，并提出正确的问题。”或许我们可以说这是科学革命带来的美德，我们“愿意承认自己并非无所不知，也愿意在知识进展之后，承认过去相信的可能是错的”。

所以与其说这本书告诉了我很多从未听闻的结论，我更想说，这本书给予了我质疑的勇气和想象力，让我意识到，很多时候我们的视角都是局限的，只有放下局中人的盲目，环视寰宇，才能贴近更加完整、更加真实的景象。
