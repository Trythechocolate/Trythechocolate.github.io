# 《午夜巴黎》

> 导演：伍迪·艾伦

## 观影体会：选择活在梦醒时分

就像做了一场梦，梦醒时分，没有人知道梦从哪里开始。

巴黎是一座什么样的城市？浪漫？奢华？闲散？电影的开头就以一组静态的镜头呈现了不同地点、不同视角下的巴黎：街角的咖啡店、华灯初上的拱桥、日落时分的摩天轮……还有林荫路上行色匆匆的旅人。这是21世纪的巴黎，我不得不承认，这的确是一座迷人的城市。但这只是第一层时空，这种嵌套式的奇妙结构实在引人入胜。

吉尔与未婚妻伊内尔随着岳父母来到巴黎旅行，不想参与舞会的吉尔带着葡萄酒的微醺感在巴黎街头独自闲逛，在一群载歌载舞的人们的盛情邀请下坐上了一驾马车，进入了一场充斥着科尔·波特的音乐的派对。在这场派对上他见到了许多20世纪的文艺界名流。这是第二层时空。在这个时空里，吉尔经历了从怀疑对方在开玩笑到感受到幸福的眩晕，有好几个镜头都十分有趣，比如当他在回味午夜奇遇时，喃喃自语道“童子军、大一英语不及格的吉尔遇到了海明威”，还有遇到艾略特的时候，他把对方的名字翻来覆去地念了好几遍。

午夜的经历给予了吉尔文学创作上的无数灵感。海明威关于好的文学创作的观点令人记忆犹新“只要故事真实，文字干净质朴，赞美直面压力的从容和无畏，就没有糟糕的主题。”格特鲁德·斯泰因这样描述作家的角色和文学的意义。“我们都恐惧死亡，质疑自己在世间的位置。作家笔下的工作是决不能屈服于绝望，而是帮助读者找到空虚生活中的寄托。”它们都帮助吉尔一点点深入文学的本质，从不信任任何人阅读自己的作品，对自己是否能够写出一部小说感到怀疑，到逐渐释放自己的想象力和创造力，在对作品的不断打磨当中也逐渐坚定自己的理想，拾起对自己的信心和对生活的掌控感。我想这也是文学对于任何人，无论是创作者、阅读者还是不经意间瞥到某个句子的过客的意义，好的文学，并不止步于让你看到别人，看到那些并不属于自己的、遥远的生活，更让你透过这面镜子看到自己。

影片当中对于爱的探讨同样深刻，我不得不把海明威的那段话一字不落的记录下来，“我相信真爱能够产生一个纾解死亡的时刻，所有的胆小懦弱都是由于没有爱或者爱得不彻底，这两者一样。勇敢而真诚的人能够直面死亡，正是因为他们的爱拥有足够的激情，可以将死亡从头脑中驱逐。”我无法去评判这个论断是对是错，直面死亡的能力与是否拥有爱相联系，但我可以确定的是，海明威经历过这种足以让他忘记对死亡的恐惧的爱，然后他将这种体会真实地记录下来，提醒人们用一个全新的视角去审视自己的爱与激情。

影片中的爱是形式多样的，吉尔与伊内尔之间的爱是基于世俗需要的结合，就像吉尔自己所说的“我们在小事上没什么问题，但大事上往往存在分歧”，但事实上，无论是日常对话还是行为选择上，两人的分歧都显而易见。吉尔是一个浪漫主义者，他享受精神世界的愉悦，比如散步、聊天、读诗……而伊内尔则是一个现实主义者，她享受舞会、酒席、派对。他们互相为对方所选择的活动感到无聊，甚至是一种煎熬。

伊内尔和保罗的爱则是基于虚荣心的相互满足，保罗乐于炫耀自己渊博的学识，而伊内尔的倾慕为他提供了恰到好处的情绪价值；对伊内尔而言，这样一个“会讲法语、知识渊博”的男人爱上自己，也证实了自身的独特魅力。这样的短暂但恰到好处的价值交换酝酿出了一段不合时宜的的云雨交欢。

吉尔和阿德里亚娜之间，我不知道究竟是因为阿德里亚娜神秘而美丽的眼睛、不经意间的夸赞，还是吉尔谦虚而天真的气质、夜空下充满诗意的对白，还是巴黎这座城市浪漫的气息，又或许是这一切共同调制出的，一种不可名状的情愫在两个素昧平生，甚至来自于不同时代的人之间悄悄蔓延。他们在巴黎的街头拥吻，一同来到美心酒店看踢踏舞，又在此永远分别。他们的分别就这样淡淡的，就像他们的相识，像一片飘荡的云絮。

由此来到影片的第三个空间：美丽时代。在高更等人的口中，我们听到了如出一辙的论调：现实太平庸了，过去才是黄金时代。至此，吉尔明白了，每一个镜头面前的我们也都明白了，每个人心中都有一个美好的回不去的过去，但那只不过是经过记忆去芜存精修修补补后的影像，是一种对时间、对事实的不忠。不可否认，我们像需要面包和空气一样需要这样的美化，否则无数的来自过去的苦难和现实面临的苦难堆积在一起，足以令人窒息。而我们在深陷现实的囹圄之时，总希望通过回味或者幻想某个完美无瑕的过去，找到一些足以支撑我们面对不堪的动力。我们太过于习惯如此，以至于几乎忘记一个事实，过去是属于那个时代的人的现实，它就像张爱玲笔下那席“长满虱子”的华美的袍，身处其中的人无需提醒便会感受到它的不堪。再怎么美好的过去也无法替代现实，尽管现实总是不如人意，但它是我们能够抓住的唯一。除此之外，我们别无选择。

有一段相似对话在整部影片中出现了三次，吉尔表达了自己对雨中巴黎的喜爱，第一次被妻子一句“被淋湿有什么好的”硬生生地怼了回去，第二次遭到了妻子和岳母共同的嫌弃，最后一次终于邂逅了与自己分享共同感受的人。或许浪漫主义会在现实生活中处处碰壁，但就像午夜等待那辆马车的旅人一般，我们会等到那个华灯点满，琴声初奏的夜晚，等到那双理解浪漫，诠释浪漫的眼睛。
